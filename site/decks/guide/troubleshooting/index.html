Troubleshooting and feedback

Missing photos, metadata, exports, templates, and sync.

iPhoneiPadMac

iPhone

Follow the workflow below on your iPhone. Use the Mac notes for desktop-specific controls.

iPad

The same workflow applies on iPad. Editing controls may appear beside the canvas in a wide window instead of below it.

A project disappeared after export

Check Archive. Archive Project After Export can move a saved project out of the main list. On iPhone and iPad, check Settings → Project Cleanup and pin projects you want to keep. Restoring a project is different from recovering a missing original photograph.

Camera or Fujifilm details are missing

Try the original file. Screenshots and edited copies may not contain camera metadata. Fujifilm decoding requires supported original JPEG MakerNotes; a recipe name is supplied by you. Use My Gear or Photo Details for information you know.

An export failed or may have saved twice

Check Photos or the destination folder before retrying an uncertain save. Use Retry Failed on iPhone/iPad or Retry Unfinished Output on Mac when offered. Try fewer pages or a smaller export width after a memory error. Keep Decks running until processing finishes.

Decks cannot save to Photos

Allow the requested Photos access, or review Decks’ Photos permission in the device’s privacy settings. On Mac, Decks → Settings → General includes Allow Saving to Photos. Export to a folder if you do not want to grant Photos saving access.

A project or template has not synced

Confirm the same Apple account and that optional Decks iCloud sync is enabled on both devices. Check status, allow media to download, and use Sync Now. Resume paused downloads on Mac when appropriate. Separate local presets are not a complete synced settings library.

A shortcut cannot find my template

Open Decks and confirm the template is saved. Reopen the shortcut’s action and select an available template. Check that input photos reach Apply Template and that its output connects to Save to Photo Album or Save File.

Send a useful report

Use Send Beta Feedback in TestFlight, or email contact@brianrenshaw.app. Include your platform, OS version, Decks build, the steps you took, and what you expected. Attach only photographs and metadata you are comfortable sharing.

Mac

Use Recent Activity to inspect processing jobs. Check Settings → Automation folder access when a file-based workflow fails. Do not assume a missing result means the operation never wrote a file; inspect the destination before retrying.
