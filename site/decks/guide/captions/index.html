Decks help/Save & Share

Write and copy captions

Prepare posting text for each page.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Home, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Write a caption

  1. Tap Caption to write for the current page. Use Preview to review the photo and finished caption together. All Captions opens the project list.
  2. Swipe left or right across the caption workspace, or use the page arrows, to change pages. Your Write or Preview mode stays selected.
  3. Type ; at the start of a word to insert photo information or your saved variables. Review the finished wording for that page.
  4. Captions are separate from text printed on the image. Exporting an image does not paste its caption into another app for you.

Copy as you post

  1. Copy Caption copies the finished wording only. More → Copy with Project Link also includes a link back to Decks.
  2. Use Copy Next in All Captions to copy the next prepared caption. Switch to the app where you’re posting and paste it.
  3. Return to the All Captions for the next page. Copied captions are grouped separately, and pages without captions appear under Needs a Caption.
  4. The More menu lets you arrange pages and reset copied status. You can also reach a project’s All Captions from Projects.

Save captions to Apple Notes

  1. From the Caption screen, open Caption More → Share Markdown, then choose Notes in the share sheet. You can also use Copy Caption and paste the text into a note.
  2. To automate notes for an existing project, connect Decks’ Get Project Captions action to Create Note in Apple Shortcuts. Render Project can provide the finished images for your workflow.

Mac

Write a caption

  1. Open Caption in the inspector to write for the current page. Add Alt Text to describe the image for people using screen readers.
  2. Under Include Photo Details, choose details such as camera or lens to add. Insert Selected Fujifilm Details adds your Fujifilm information.
  3. Save wording you reuse with Save Caption Preset, then choose it from Caption Presets on another page.
  4. Captions are separate from text printed on the image. Exporting an image does not paste its caption into another app for you.

Copy as you post

  1. Copy Captions copies the captions for every page, in page order. Copy Markdown copies them as Markdown.
  2. Switch to the app where you’re posting and paste.

Save captions to Apple Notes

  1. Click Copy Markdown in Caption, then paste the text into a note.
  2. Or choose File ▸ Run Workflow…, set Destination to Apple Notes, and click Prepare Workflow. Share the prepared files, or use Copy Text beside each document.
  3. In Apple Shortcuts, Decks’ Get Project Captions action can pass a project’s captions to Create Note.
