Decks help/Save & Share

Export your photos & clips

Output settings, saving, sharing, and retries.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Home, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Save or share

  1. Open Export in the editor. Pages saves each page as designed; choose all pages or the current page where offered.
  2. Open Export Settings to choose width in pixels, JPEG or PNG, sharpening, and other output settings. JPEG also has quality and file-size controls; projects with video offer video output options.
  3. Review the previews, then tap Save to Photos or Share. Allow Photos access when requested so Decks can save the result.

Metadata and filenames

  1. In Export Settings, choose whether to include location and contact details in the exported file’s metadata.
  2. Use Filename Pattern to control filenames. The listed tokens can insert the original base name, date, page index, or camera information.
  3. Allow Enlarging lets an output grow beyond its normal source-size limit. It does not add detail to a small original.

Keep a project in Projects

  1. Turn off Archive Project After Export if you want the project to remain in Projects after saving or sharing.
  2. Change the default in Settings → Project Cleanup. An archived project is still available under Projects → Archive.

If an export is interrupted

  1. Keep Decks open while a large export finishes. Use Retry Failed when offered; confirmed saves are not repeated.
  2. If Decks asks whether images were saved, check Photos before choosing the saved or retry option.
  3. For a memory error, try a smaller export width or less crop zoom, then retry. Settings → Recent Activity also lists processing runs and available retry actions.

Mac

Save or share

  1. Choose File ▸ Export… (⇧⌘E), or click Export in the toolbar. Decks exports every page of the project as designed.
  2. Choose JPEG or PNG and an Image Width in pixels. JPEG Quality controls compression; projects with video use the Video Width under Video.
  3. Click Save to Photos, or Export to Folder… to choose a folder. When it finishes, click Reveal in Finder or Share.
  4. Click Continue in Background to keep working while a large export runs.

Metadata and filenames

  1. Turn Include Location on or off to choose whether location is kept in the exported file’s metadata.
  2. Use Filename Pattern to control the names of exported files.

Keep a project in Projects

  1. Exporting on your Mac leaves the project in Projects. Archive it yourself when you’re done: Control-click it and choose Archive.
  2. After your first finished export, Decks offers once to save the design as a template. Choose Not Now to skip it.

If an export is interrupted

  1. If an export fails or you cancel it, click Retry Unfinished Output. Finished files are kept and not repeated.
  2. Recent Activity in the sidebar (⌘5) lists exports with Cancel, Retry, and Reveal Output. If Decks quits during an export, retry it there.
  3. For a memory error, try a smaller Image Width or less crop zoom, then retry. If saving to Photos is refused, allow Photos access in System Settings, or export to a folder instead.
