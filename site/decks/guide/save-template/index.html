Create your own template

Save a reusable design, then try it with new photos.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Layout Builder, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Save a sequence of designs

  1. In Arrange Pages, tap Select and choose the pages you want. Save as Template preserves those designs in project order.
  2. A single-photo page followed by a two-photo page becomes one reusable two-page template. Add → Add Pages from Template repeats the sequence with your new photos, using this project’s size.
  3. Use Duplicate Page in the page menu, or Duplicate Pages in Arrange Pages, to copy photos and edits within the current project. Panorama panels stay together.
  4. Apply Template to Project changes the existing project’s layouts. Add Pages from Template appends new pages while keeping the current pages.

Start in Templates

  1. Open Home → Templates → Create Template. Build the layout with the preview photos, then set its background, frames, text, and optional camera details.
  2. Use Template Preview to try your own photos, show empty photo slots, or preview a repeating batch.
  3. Save and name the template. Preview photos and their photo details are not saved as template content.

Save from a project

  1. In Export, tap Save as Template. Choose pages to include, name the design, and choose whether to include text wording. Photos and crops stay with the project.
  2. Your template appears in Templates. Tap Use from Photos in Export for shortcut setup instructions.

Use and manage saved templates

  1. Tap a template in Templates, then choose Use Template to add a new set of photos, or Edit Template to change the design.
  2. Use Template Options to rename, duplicate, share, delete, or make it your default. Mark favorites to keep preferred designs handy.
  3. Tap Import Template in Templates to open a shared template file. Camera-detail templates belong in the Camera Details library.

Mac

Save a sequence of designs

  1. ⌘-click or ⇧-click pages in the page strip, then Control-click one and choose Save 2 Pages as Template… (the number matches your selection). Decks keeps those designs in project order.
  2. A single-photo page followed by a two-photo page becomes one reusable two-page template. File ▸ Add Pages from Template… repeats the sequence with your new photos, using this project’s size.
  3. Control-click a page and choose Duplicate Page to copy photos and edits within the project, or press ⌘D when no text is selected. Panorama panels stay together.
  4. The Templates menu in the toolbar applies a saved template to this project’s pages. Add Pages from Template… adds new pages while keeping the current ones.

Start in Templates

  1. Click Templates in the sidebar, then Create Template (⌥⌘N). Build the layout with the preview photos, then set its background, frames, text, and optional camera details.
  2. Click Save Template in the toolbar and name it. Preview photos and their photo details are not saved as template content.

Save from a project

  1. Choose File ▸ Save as Template… (⇧⌘S). Choose pages to include, name the design, and choose whether to Include Text Wording. Photos and crops stay with the project.
  2. If a template already has that name, choose Replace Template or Keep Both. Your template appears in Templates.

Use and manage saved templates

  1. In Templates, click Use Template to start a project with new photos, or Edit Template to change the design. To rename it, edit the name at the top of the window, then click Save Template.
  2. Control-click a template to Favorite it, Set as Default, Export Template…, Duplicate, or Delete…. Favorites appear first.
  3. Click Import Template… to add a template file someone shared, or double-click the file in Finder.
