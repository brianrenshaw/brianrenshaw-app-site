Panoramas for a carousel

Split a photo into panels and preview the swipe.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Layout Builder, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Set up the panels

  1. Choose Panorama in Layout Builder. Pick the panel size and number of panels, then add your photo.
  2. Use Preview Panorama to see adjacent rounded panels in a horizontally scrolling preview, like a Threads carousel.
  3. In an existing project, the editor’s options also offer Split Photo into Panorama Panels.

Export and post in order

  1. Open Export and check the panorama preview. Export all the panels you want to share.
  2. In Threads or Instagram, select the exported images in their panel order to build the carousel. Decks prepares the files; you choose and publish the post in the destination app.

Mac

Set up the panels

  1. Choose Panorama in Layout Builder and pick your photo. Set the number of linked panels, from 2 to 6.
  2. In an existing project, select a photo and choose Edit ▸ Split Panorama into 3 Pages, or click the same button in Layout.
  3. Panels stay together when you select, duplicate, or delete pages in the page strip.

Export and post in order

  1. Choose File ▸ Export…. Each panel becomes its own image, in order.
  2. In Threads or Instagram, select the exported images in their panel order to build the carousel. Decks prepares the files; you choose and publish the post in the destination app.
