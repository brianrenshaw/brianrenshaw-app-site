Decks help/Make It Yours

Adjust, reset & undo

Restore the starting look without losing your place.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Layout Builder, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Reset one adjustment

  1. Drag a slider to change a value. Double-tap the slider to reset it, or use its visible Reset control.
  2. With VoiceOver, select the adjustment and use its Reset action. All three methods restore the same value.
  3. Reset returns to the selected template’s baseline. If the template has no value for that control, Decks uses the control’s initial default. Ordinary edits and reopening the project do not redefine that starting point.

Undo a change

  1. Use Undo in the editor to reverse an edit, including a reset. Redo reapplies a change you have undone.
  2. Reset one adjustment when you only want to restore that setting; other edits stay in place.

Mac

Change or reset an adjustment

  1. Drag a slider to change a value, or type an exact value in the field beside it and press Return.
  2. In Layout ▸ Guides, Reset Page clears this page’s own changes so it follows the All Pages settings again.
  3. Edit ▸ Reset Layout… returns every page to how it was before your first layout change in this session. You can undo it.
  4. In the walkthrough, Reset beside Frame Thickness or Shadow Strength returns that slider to the layout’s starting value.

Undo a change

  1. Choose Edit ▸ Undo (⌘Z) to reverse an edit, including a reset. Redo (⇧⌘Z) reapplies a change you have undone. Both are in the toolbar, too.
  2. Reset only what you need; other edits stay in place.
