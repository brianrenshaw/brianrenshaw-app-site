Projects and templates with iCloud

Keep projects and templates available across your devices.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Layout Builder, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Sync across Mac, iPhone, and iPad

  1. Open Settings → iCloud and turn on Sync with iCloud on your devices using the same private iCloud account.
  2. Sync includes projects, templates, and the photo copies those projects need. Use Sync Now and check the status message if a change hasn’t appeared yet.
  3. Let sync finish before continuing the same project on another device.

Use a template from Photos

  1. Save a reusable template first. Then open the Photos & Shortcuts guide below for the Decks Templates shortcut or manual setup.
  2. Save Photos with Template produces finished images without adding a project. Use Create Project from Photos when you want to edit the result in Decks.
  3. For an interrupted automation, open Settings → Recent Activity to inspect the run and retry where available.

Mac

Open Decks → Settings → General and enable Sync Decks with iCloud. Use the same Apple account on each device. Check the status message and use Sync Now. Pause Downloads and Resume Downloads appear when applicable. For Mac automation, open Settings → Automation; the app documents a Select Photos → Apply Template → Save File or Save to Photo Album workflow.
