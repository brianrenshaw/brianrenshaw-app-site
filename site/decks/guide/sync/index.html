Sync & Shortcuts

Continue on iPad or reuse a template from Photos.

iPhoneiPadMac

iPhone

Start with the steps below. Editing tools appear beneath the canvas; tap the active tool to hide or show its controls.

iPad

Use the same task steps. The sidebar gives you access to Layout Builder, Templates, and Projects. In a wide editor window, controls can sit alongside the canvas; narrower windows use the compact panel. A missing control may be inside a collapsed section or the page’s options.

Sync across Mac, iPhone, and iPad

  1. Decks syncs through your private iCloud account on every device signed in to the same Apple Account. It’s on unless you turn it off in Settings → iCloud.
  2. Sync includes projects, templates, your settings (destinations, favorites, My Gear, recipes, and presets), and the photo copies those projects need. Appearance stays on each device. Use Sync Now and check the status message if a change hasn’t appeared yet.
  3. Let sync finish before continuing the same project on another device.

Use a template from Photos

  1. Save a reusable template first. Then open the Photos & Shortcuts guide below for the Decks Templates shortcut or manual setup.
  2. In Apple Photos, select your photos, tap Share → Decks Templates, and choose a saved template. Finished copies return to Photos without adding an editable project.
  3. After setup, small photo batches can run without opening Decks. More than eight photos, video, or a Photos permission request may bring the app forward.
  4. For a custom shortcut, connect Shortcut Input to Apply Template, then Save to Photo Album or Share. Save Photos with Template combines processing and saving. Use Create Project from Photos when you want to edit the result in Decks.
  5. For an interrupted automation, open Settings → Recent Activity to inspect the run and retry where available.

Mac

Sync across Mac, iPhone, and iPad

  1. iCloud sync is on by default. Use the same Apple Account on each device. To keep work on this Mac only, turn off Decks ▸ Settings… ▸ General ▸ Sync Decks with iCloud.
  2. Sync includes projects, templates, and the photo copies those projects need, plus settings such as destinations, favorites, My Gear, Fujifilm recipes, caption and workflow presets, Layout Builder order, and keyboard shortcuts on your other Macs. Appearance stays separate on each device.
  3. The bottom of each window shows sync status. Click Sync Now in Settings ▸ General if a change hasn’t appeared yet.
  4. Let sync finish before continuing the same project on another device.

Use a template from Photos

  1. Save a reusable template first. Then, in the Shortcuts app, add Select Photos, Decks’ Apply Template, and Save to Photo Album or Save File.
  2. Apply Template returns finished copies without adding an editable project. Save Photos with Template saves straight to Photos. Use Create Project from Photos when you want to edit the result in Decks.
  3. Before a shortcut saves to Photos, click Allow Saving to Photos in Decks ▸ Settings… ▸ General.
  4. For Terminal, AppleScript, and folder access, see Automate on your Mac.
