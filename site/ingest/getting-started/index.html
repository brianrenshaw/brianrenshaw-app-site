Ingest / Getting started

From your SD card to Lightroom.

Learn the flow in about five minutes. Plug in a card, review the keepers, add shoot details, then copy and verify. Save your setup when you’re ready.

You’ll need an Apple silicon Mac with macOS 15 or later, a card reader or photo folder, and a destination with enough space. Lightroom Classic is optional. Transfer time depends on your card, drive, and files.

Add details when you’re ready. Open Metadata Assist with ⌘’. Choose a field, enter your details, and review before you use them for import. Tab fills suggestions from your history. Metadata Assist guide →

Start with ⌘K. In the app, the Command Palette finds commands, folders, and saved workspaces. On this website, the same shortcut searches the site and docs. You don’t have to memorize every shortcut.

Meet the palette →

The app shows this walkthrough on your first launch. Reopen it through Help → Walkthrough: Card to Lightroom, or type “walkthrough” in ⌘K. You can leave for Settings and return to the same step while the app stays open.

1. Insert2. Review3. Metadata4. Copy5. Set up

  1. Plug in your SD card.

    With Ingest running, insert your camera card. A newly detected card opens in the Ingest tab when Settings → Transfers → Open a card when it is inserted is enabled. It is on by default. If the card was connected before you launched Ingest, choose it from Cards & Drives.

    Your source is on the left, photos are in the center, and your copy setup is on the right. For a photo folder, use the + beside Folders. Choose your destination under Customize Import → Save Location; no copy starts until you click Ingest.

    Find it with ⌘K: type “Ingest” or “Find Folder”.

  2. Review your keepers.

    Use the arrow keys to move through the shoot. Press T to tag a keeper; press it again to untag. Space opens a larger Preview and returns to your previous view.

    Choose Show: Tagged above the grid to see your tagged photos. Select the photos you want, then choose Selected photos above the Ingest button. Review the destination and file count before starting the copy. A checkmark means tagged. Filtering alone does not limit an import set to All source photos.

    Select two photos and press C to compare. In Preview, Z toggles Fit / 100%. Find Grid Loupe, Focus Peaking, and Detail Overlay in the View menu. Stack review keeps bursts and exposure brackets together.

    These are the default keys. Your customized shortcuts appear in the app walkthrough. See the keyboard reference or open Settings → Shortcuts.

    Find it with ⌘K: type “Tag” or “Show Tagged Only”.

  3. Add shoot details with Metadata Assist.

    In Ingest, choose Edit beside Shoot details, or press ⌘’ to open Metadata Assist. Choose Keywords, Caption, or Location and enter a value. Tab fills suggestions from details you have used before.

    Check Review changes. Use Edit Individual Fields for detailed IPTC editing, or Find place for map coordinates. Choose Use for Import to save the reviewed details to this import. They are written to the copies when you ingest; card originals stay unchanged.

    For individual photos, select them and choose Metadata → Edit Metadata. In Browse, Apply writes to the selected files; check the scope before applying.

    Metadata Assist guide →

  4. Copy, back up, and hand off to Lightroom.

    In the right sidebar, open Customize Import → Save Location and choose your destination. For a second copy, choose Add Backup and select a folder on another drive. Ingest writes and verifies both copies in the same job.

    Before copying, open Customize Import → After Import and select Open in Lightroom Classic. Check the file count and planned destinations, then click Ingest. After the copy succeeds, Classic opens those copied files for you to review and confirm its import.

    Classic must be installed. If its action is missing or the app lives elsewhere, configure it in Settings → Automation. You can also import the destination folder from Classic yourself. Set up the Lightroom handoff →

    For your first import, keep Leave the card alone. Wait for the verification result before ejecting. Understand copy and verification results →

  5. Ready for an advanced setup?

    Create a workspace for each kind of photography in Settings → Workspaces. Save destinations, backups, naming, metadata, and viewing preferences instead of rebuilding the same job every time. The Ingest settings group destinations and naming first, with additional file, metadata, and card options available when needed.

    • Personal: simple folders and optional Apple Photos.
    • Real Estate: address-based names and exposure brackets.
    • Weddings: dated jobs, keywords, and a backup.

    Set up workspaces →   Metadata presets →   Automation →

    Apple Photos has a global switch in Settings → General and a switch for each workspace. Keep it on for Personal and off for Real Estate; the global switch must also be on. Learn about Apple Photos →

    One shortcut to keep: ⌘K. In the app, type “Workspace” to find your saved setups, “walkthrough” to revisit these steps, or the name of whatever you want to do next. On this site, ⌘K searches pages and sections the same way.

Try it at your own pace.
