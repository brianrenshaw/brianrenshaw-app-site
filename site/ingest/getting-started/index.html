Start here: your first shoot

Open a card or folder, choose keepers, add details, and import verified copies. Save the setup for next time.

You’ll need an Apple silicon Mac with macOS 15 or later, a card reader or photo folder, and a destination with enough space. Lightroom Classic is optional. Transfer time depends on your card, drive, and files.

On first launch, Welcome to Ingest offers an optional overview of the Command Palette, Workspaces, review, Photo Groups, Metadata Assist, and Decks. Jump to any topic, then choose whether to build your first workspace at Get Started. Reopen it through Help → Welcome to Ingest or the Command Palette. The steps below walk through your first import.

  1. Plug in your SD card.

    With Ingest running, insert your camera card. A newly detected card opens in Browse when Settings → Transfers → Open a card when it is inserted is enabled. It is on by default. If the card was connected before launch, choose it from Cards & drives.

    Choose a source in the left sidebar, or press ⌘O to open a photo folder. Browse is where you review photos. Import… in the toolbar opens Import Settings; opening it does not start a copy.

    Find it with ⌘K: type “Open Folder” or “Find Folder”.

  2. Review your keepers.

    Use the arrow keys to move through the shoot. Press T to tag a keeper; press it again to untag. Space opens a larger Preview and returns to your previous view.

    Choose Show: Tagged above the grid to revisit your keepers. When you open Import…, its scope starts at Selected if photos are selected, otherwise All. Choose Tagged explicitly to copy your tagged photos. Browse filters and import scope are separate. Check the count in Import Settings; an empty scope stays empty.

    Select two photos and press C to compare. In Preview, Z toggles Fit / 100%. Find Grid Loupe, Focus Peaking, and Detail Overlay in the View menu. Stack review keeps bursts and exposure brackets together.

    These are the default keys. Your customized shortcuts appear in the app walkthrough. See the keyboard reference or open Settings → Shortcuts.

    Find it with ⌘K: type “Tag” or “Show Tagged Only”.

  3. Add shoot details with Metadata Assist.

    Open Import…, then choose Edit Shoot Details beside Shoot details. Metadata Assist stages shared details for this import. Choose Keywords, Caption, IPTC Place, or GPS Location, or type ; to find a field. Tab completes remembered values.

    Check Review changes. Use Edit Individual Fields… for detailed IPTC fields, or Find or use saved place… for a map location. Choose Use for Import to return the reviewed draft to Import Settings. Details go to verified copies; card originals stay unchanged.

    For existing writable files, select photos in Browse and press ⌘’. Here, Apply writes the reviewed metadata to those files or their RAW sidecars. Check the photo scope before applying. Import shoot details and edits to existing files are separate uses of the same editor.

    Metadata Assist guide →

  4. Copy, back up, and hand off to Lightroom.

    In Import Settings, choose Save to under Destination. Add a backup destination on another physical drive if you want a second verified copy. Review Subfolders and Filenames, then inspect the output paths on the right.

    Use a separate physical drive for Photo Backup. Ingest’s second verified copy is one part of a backup workflow: arrange off-site protection and editor/catalog backups separately. A Lightroom catalog backup does not back up your original photographs. See 3-2-1 backup guidance.

    Optionally expand After Import, add Open in Lightroom Classic, and choose Photos for this action. For example, import All while opening only Tagged copies in Classic. Check the import count, action count, and destinations, then click Import. After copying, metadata processing, and verification succeed, Classic receives the matching files for you to review and confirm its import.

    Classic must be installed. If its action is missing or the app lives elsewhere, configure it in Settings → Automation. You can also import the destination folder from Classic yourself. Set up the Lightroom handoff →

    For your first import, keep Leave the card alone. Import Progress opens automatically; Continue Browsing lets you keep working. Wait for Import Complete and the verification result before ejecting. Understand copy and verification results →

  5. Save the setup for next time.

    Open Settings → Workspaces → New Workspace… and choose the guided Workspace Builder or direct section editing. Start with a name and destination, keep original filenames, then review and save. Optional questions, photo groups, naming, metadata, and after-import actions can be added when you need them. Import Folders and Import File Names configure imports. Organize stores separate choices for existing photos. Save keeps the draft; Cancel leaves your setup unchanged. Use Workspace applies it without starting an import.

    Project folders that separate source photographs from outputs are an approach also used by Capture One Sessions. The homepage examples (Wedding, Landscapes, Personal, Headshots, Events) are adaptable starting points with fictional job names — not mandatory standards.

    • Wedding: capture-order Grid, burst grouping, client filenames, and a backup.
    • Landscapes: Split view, scene grouping, and original camera filenames.
    • Personal: simple folders, Preview, and optional Apple Photos.
    • Headshots: client filenames, paired RAW + JPEG, and video excluded from import.
    • Events: event filenames and a workspace TSV file of caption codes.

    Set up workspaces →   Metadata templates →   Automation →

    Apple Photos has a global switch in Settings → General and a switch for each workspace. Keep it on for Personal and off for Headshots; the global switch must also be on. Learn about Apple Photos →

    One shortcut to keep: ⌘K. In the app, type “Workspace” to find your saved setups, “walkthrough” to revisit these steps, or the name of whatever you want to do next. On this site, ⌘K searches pages and sections the same way.

Try it at your own pace.
