Cards and folders

Put a card in and it appears in the sources list. A newly inserted camera card opens in Browse when Settings → Transfers → Open a card when it is inserted is on. Cards connected before launch remain available in the sidebar. Press ⌘O to open a folder instead. Available previews load progressively while Ingest reads the source.

Click the sidebar magnifier, press ⇧⌘F, or choose Find Folder in ⌘K to search folder names in a roomy palette. Results include parent paths; Escape closes the palette without changing the tree. Current, recent, and favorite folders appear immediately, with other results supplied by Spotlight.

The sidebar keeps your Mac’s folder tree in place. Single-click a folder to navigate in the current Browse tab; double-click to open it in a new tab. Command-W closes the current tab before the window.

Favorites, Recent, and Saved Views have collapsible sections. Use Add to Favorites from the menu or command palette. ⌘D deselects photos. Show photos in subfolders is visible beside the folder name and defaults off; when enabled, selecting a photo identifies its containing folder. Finder’s Open With Ingest opens the photo’s folder and selects it.

⌘[ and ⌘] go back and forward through what you have opened, like a browser, so switching to the card and back to yesterday's folder costs one keystroke.

⌘E ejects. Ingest closes every file it has open on the card first, which is why eject does not fail with the usual complaint about a file in use. If a card disappears, Ingest closes the source and cancels an active import. Verified copies are retained; check the result for incomplete groups.

There is also a menu bar item, on by default, showing the progress of a running ingest, the cards that are in, and your recent folders. It is there so a copy can run while you work in another app.
