Destinations

Favorites give you quick access to folders you use often. Add to Favorites is available in the menu and command palette; ⌃⌘1 through ⌃⌘9 open the first nine favorites. Find them by name in ⌘K as well. Ingest destinations and routing are saved with the workspace.

An ingest can write to two destinations at once. The second copy is made from the first one after it has been verified, and it is checked the same way.

The active workspace supplies import defaults. Open Import… to review or adjust a single job. Edit the Import Folders and Import File Names sections in Settings → Workspaces to save destinations, naming, and routing for reuse.

Keep archive organization separate

The workspace’s Organize section saves a separate destination and naming setup. Rename in Place changes filenames only and ignores that destination and folder structure.
