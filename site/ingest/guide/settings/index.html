Settings

⌘, opens a window with a search field. Everything the app stores is in there with a real control: folder and app choosers instead of typed paths, pickers instead of remembered strings, live previews for templates, snippets, and splits, and drag to reorder wherever the order decides a number key.

Ordinary app settings apply as you edit them. Workspace, template, and action editors use explicit Save and Cancel. Settings search filters the available results; choose a result or press Return to navigate to its control. Supported changes can be undone with ⌘Z while the window is open. Settings → Advanced exports configuration to carry to another Mac, described on the automation page.

There is one row that is not a setting. On the Browsing page, Memory cards are never modified has a lock beside it instead of a switch. It is listed so that the rule is visible, not so that it can be turned off.

Keywords

Keywords are descriptive words or phrases, separate from the on/off review tag. Ingest builds keyword suggestions from photographs it has read. Folders record their keywords as they are read, and the Photos library is read in full after it connects, so a keyword that exists only in Photos can appear in a folder’s keyword suggestions without opening Apple Photos. Photos keywords need macOS 27.

Settings → Keywords lists known keywords with their Photos counts and folder locations. Select one or more and rename, merge, change case, unify spellings, remove from suggestions, or delete.

Every change shows a preview first: how many photographs in Photos, how many files in each open folder, and how many files sit in folders that are not open, which keep the old spelling until you open them. Photos is changed in batches and a failed batch is reported without stopping the rest; open folders go through the verified metadata path and sit in Undo, and the receipt offers Revert.
