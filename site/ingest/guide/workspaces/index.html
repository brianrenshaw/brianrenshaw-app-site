Workspaces and the guided builder

A workspace remembers folders, filenames, metadata, and review preferences for a kind of photography. Import and Organize have separate settings.

Choose a workspace

Use the window toolbar or Workspace menu. Open at Launch is separate from the active workspace. Control-0 selects Basic; Control-1 through Control-9 select assigned workspaces.

Create a workspace

Choose New Workspace…, then Use Workspace Builder for guided steps or Set Up Manually for direct access to the same sections. Changes stay in a draft until you choose Save Workspace. Cancel leaves your saved setup unchanged.

Preview a starting point

Start with Build from scratch, Events, Headshots, or Real Estate. Expand a starter to see its folders, filenames, and import questions. Expanding it only previews the setup; choose its Use button to apply it to your draft.

  • Build from scratch: a dated import folder and original camera filenames.
  • Events: a project with photo numbering that continues across cards, stacked bursts, and separate video folders.
  • Headshots: a project per client, session folders, similar-frame stacks, and a Selects destination for tagged photos.
  • Real Estate: address-based folders for originals, video, edits, exports, and floor plans, with exposure brackets stacked.

Applying another starter replaces the draft’s workflow choices. If you have edited the draft, review the confirmation before continuing. You can customize the result afterward.

Work through eight sections

Workspace, Import Folders, Import File Names, Organize, Browse & Review, Metadata, After Import, and Review & Save. Questions are part of the variables you insert; Photo Groups are configured in Import Settings.

Choose folders and filenames

Import Folders asks where photos go, whether each import gets its own folder, which empty folders to create for later work, which files you normally import, and whether to make a backup. Photos go here identifies the receiving folder. Empty Edits or Final Exports folders do not receive copies automatically.

Keep original filenames or build names from text and variables. Insert Variable offers Photo Number first, followed by other naming pieces and questions. Open What do the variables mean? for examples. Import and Organize retain independent destinations and naming patterns.

Ask only for details you use

Choose an answer variable such as Client or Shoot name, or add New Question… from Insert Variable. Questions are asked at import only when a folder name, filename, or metadata template uses them. Check You’ll be asked at import to see the actual questions. Project answers are reused for the job; shoot answers belong to that session.

Photo Groups are separate from folder grouping. Use them in Import Settings when a shoot needs named groups. Continuing the same shoot can retain group numbering across cards; a new shoot starts fresh. Review import scope and numbering before the next card.

Review and save

Review & Save summarizes Import and Organize separately, with Edit links to their sections. Check the examples, then choose Save Workspace. Use Workspace applies the saved setup; it does not start an import. Connect external destinations while configuring them and reselect a destination after renaming its drive.

Camera matching and Apple Photos

Camera matching can choose a workspace when a card opens; a workspace chosen by hand takes precedence. Apple Photos requires both Settings → General integration and the workspace’s Apple Photos switch. Focus Mode (F) hides surrounding controls without changing saved panel preferences.
