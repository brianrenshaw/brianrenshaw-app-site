Share photos and folders through Messages or Email

Share selected photos

  1. Select the photos you want to share.
  2. Open the photo context menu or press ⌘K and choose Send Photos via Messages… or Send Photos via Email….
  3. Check the file count and total size. For multiple files, choose Attach Files or Create ZIP. A single file offers Continue.
  4. Review the draft in Messages or your email app, add recipients, and send it there.

Ingest opens a draft; it does not send the message. File-based sharing uses the selected visible photos’ primary files in their existing formats. It does not automatically turn RAW files into JPEGs or attach XMP sidecars.

Share a folder

Use the folder’s context menu, or find Send Folder via Messages… or Send Folder via Email… in the Command Palette. Folder sharing includes photos and videos independently of the grid’s filter or selection.

An ordinary folder includes directly contained media. Cards, volume roots, and the current folder with subfolders enabled include nested media too. Hidden files, symbolic links, unrelated files, and sidecars are excluded. Check the count before continuing.

Share from Apple Photos

Select still images and use the photo sharing commands. Ingest prepares rendered copies that preserve Photos edits. This path does not support Apple Photos video sharing.
