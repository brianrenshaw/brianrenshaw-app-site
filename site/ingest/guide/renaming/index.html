Renaming

Keep original filenames for the simplest import, or compose readable pieces in File Names. Use Add Piece to insert a date, a sequence, a photo group, or an answer from workspace questions. The live example shows the result. Advanced edits the same pattern as text: {yyyy}{mm}{dd}-{seqn} gives 20260912-7078. The full naming reference explains tokens and saved numbering.

Renaming happens during an ingest, or in place afterwards with ⌘R. ⌥⌘R re-sequences what is on screen, which is how you close the gaps in the numbering after throwing half a shoot away.

Every rename records the original filename inside the file, so Undo Rename can put the old names back later, even in a folder you opened fresh.
