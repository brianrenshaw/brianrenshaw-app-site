After-import actions, Lightroom, and automation

An action is a list of steps that opens files in an app, reveals them in Finder, sends them to Apple Photos, copies them elsewhere, or runs a Shortcut or script. In the workspace’s After Import section, add ordered actions and choose Photos for this action independently for each. For example, import All and open only Tagged copies in Lightroom.

They are built in Settings → Automation, with a button that runs one on the current selection so you can test it without waiting for a card. The detail, including what a script gets handed, is on the automation page.

Import everything; open only tagged copies

  1. Set Photos to import to All.
  2. In the workspace’s After Import section, add an action that opens files in your chosen editor.
  3. Set Photos for this action to Tagged. Review that action’s count independently of the import count.
  4. Start the reviewed import. The action works on the imported copies within its own scope.

Opening files in Lightroom hands them to that app; it is not a promise that Lightroom silently completes its catalog import. Use the completion details to review skipped or failed actions. Troubleshoot after-import actions →
