What’s new in Ingest

Ingest 0.8.2

Culling, inspection, and ingest

  • Review photos with local rejection, reviewed status, and protection. Tagging clears rejection; rejecting clears the tag. Stars and color labels remain independent. Protected photos explain why editing is unavailable, and mixed selections show which photos can be edited.
  • Compare / C opens Select and Candidate side by side. Keep Select fixed while browsing candidates, promote a candidate with Up, or swap with Down. Decisions apply to the active pane. Double-clicking a stack still opens its whole-stack grid, also available through Survey / N. Hold B for a temporary reference view.
  • Hold Z over a grid thumbnail for a loupe without changing selection. In Preview, Z toggles fit and 100% once per press. Inspection and comparison work with filesystem sources and Apple Photos, including cloud download feedback.
  • Review Similar Photos adds group navigation and progress when needed. Keep This Frame is additive, so a group can have several keepers. Suggest Keepers shows thumbnails, alternatives, and reasons before an explicit Tag Suggested Photos action; it never rejects alternatives or assigns stars.
  • Crop & Straighten is directly searchable in the Command Palette and opens inside Preview. Keyword editors wait for successful writes before closing, preserve drafts on failure, and explain protection. Metadata editing adds Apply & Previous.
  • Sharpness analysis treats dark, low-contrast, and exposure-bracket images more cautiously. Subject close-ups and persistent analysis corrections help with inspection; uncertain analysis is explained instead of presented as a good result.
  • Saved views gain review and metadata filters. Source Summary counts can become filter chips. Add metadata list view, temporary grouping, filename pick lists, portable decisions, Browse source tabs, custom ordering, and controller mappings through Settings.
  • Preserve supported editor sidecars and uniquely matched filesystem Live Photo companions through file operations. Ambiguous associations are explained before the affected operation proceeds.
  • Ingest gains per-photo inclusion checkboxes, per-project numbering, and browsing of verified destination copies while copying continues. Rejected photos are excluded by default, with Include Rejected available. Cleanup respects excluded and protected originals; decisions transfer to verified copies.
  • Keep the default browsing layout quiet: review controls appear in their relevant views, preferences live in Settings, and a single source tab stays hidden. Fix stack activation so it continues to show all frames rather than entering the two-photo comparison.

macOS 15 or later, Apple silicon. Native Apple Photos captions, keywords, and star ratings require macOS 27. Get started.
