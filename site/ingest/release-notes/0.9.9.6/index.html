What’s new in Ingest

Ingest 0.9.9.6

  • New Workspace is plain: each step is a few short groups of labeled settings, with explanations in tooltips instead of paragraphs. Choices are buttons and pop-up menus, and orange marks only Next, Save and what is selected.
  • New Workspace opens straight on its first step. The Use Workspace Builder / Set Up Manually choice is gone.
  • Starters are one row: Scratch, Events, Headshots, Real Estate. Click one to preview it beside the steps, then Use … Setup under the preview.
  • Click Photo Number in a name to set where it starts and how many digits it has.
  • Review & Save is one list, with Edit beside each step.
  • Type a camera model under For cameras with Add…. Before, a camera could only be added from the folder that was open.
  • Setting up folders is one short card, in New Workspace and in Import settings: the main folder, a new folder for each import, its subfolders, where photos, JPEGs and videos go, and the backup, each one setting, with the folder tree beside it showing the result. Tagged, keyword and rating rules are under More rules.
  • Videos can go to another location: choose Another Location… under Videos go to. Each import gets the same folder there as the photos get.
  • Import settings offers your last project: Continue [project] under the Project row, for the most recent project from the last two weeks, this workspace's first. Nothing joins until you click. Projects you start remember their workspace.
  • Import settings shows where the files go as a folder tree, with the path of the photo you click beneath it.
  • After an import, each folder it wrote to opens in its own tab, like Photo Mechanic: RAWs on one drive and JPEGs on another open as two tabs, the main one in front. The card's tab stays open.
  • Tabs show what they are, with an icon for a card, a drive folder, a Mac folder or Apple Photos, and the current tab stands out.
  • The sidebar works from the keyboard like the Finder. ↑ and ↓ step through folders and open each one, → opens a folder's subfolders and steps into them, ← closes them and steps out to the parent, and Return goes into the photos. Rating and tag keys still act on the photos from the sidebar.
  • ⌘L opens a place search: pick a place and Apply sets the GPS location Apple Photos maps and the IPTC city, state and country.
  • Edit metadata while browsing a memory card. Captions, keywords, map locations, IPTC fields, Metadata Assist, templates, Paste Metadata and photo suggestions work on a card. The card itself is never changed: your edits are held and written to the copies when you import. The inspector shows held values with a Pending note, and Discard or ⌘Z takes them back. Held edits are kept if you close the tab or quit before importing.
  • Fujifilm recipe notes queued on a card now reach the copies when you import with ⌘G.

Rotate, crop, Adjust Capture Time and Remove GPS still need the copies, since they change the file itself.

Fixed:

  • Imports started from Import settings didn't open the destination folder afterward.
  • Fujifilm JPEGs edited in Lightroom showed "Simulation unavailable" though their recipe named the film simulation. Ingest now reads it from the recipe saved at import.
  • Choosing RAW and JPEG in different folders in Import settings left the JPEGs beside their RAWs. They now go to a JPEG folder.
  • The Include and Card menus in Import settings, and the histogram and Linked Zoom menus, showed every choice grayed out.

Requires macOS 15 or later and an Apple silicon Mac.
