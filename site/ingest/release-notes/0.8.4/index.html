What’s new in Ingest

Ingest 0.8.4

Quiet depth, clearer browsing

  • Subtle dark sidebar surfaces, distinct selection and hover states, compact scene headings, clearer stack badges, and a quieter inspector keep photographs prominent.
  • Find Folder opens in the Command Palette through ⌘K, ⇧⌘F, or the sidebar magnifier. Results include parent paths and leave the folder tree intact. The Search This Mac photo-search dialog is removed; ⌘F still filters the current collection.
  • Show or hide the left, right, or both sidebars through toolbar buttons, the View menu, and palette commands. Each workspace remembers visibility; hidden panes retain their widths and contents.
  • Sort and Group have separate controls. Browse by metadata in a facet strip: click one value or Shift-click several. Counts respect other active filters without reorganizing the grid.
  • Cards and drives share a section. Recent folders show five entries plus the current folder, with an option to reveal more. Expanded branches refresh when directories change.
  • Organize opens directly into its workspace. Review & Organize still precedes file changes. Ingest and Social Export gain compact source, project, and action layouts.
  • Scene navigation, sidebar focus recovery, and uninterrupted filter typing through empty results are more dependable.

Saved filters, custom ordering, and photo workflows remain available. Read the browsing guide.
