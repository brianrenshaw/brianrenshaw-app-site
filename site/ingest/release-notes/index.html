Ingest / Release notes

A record of what’s new.

What changed in each version. Ingest can check for updates itself, from the Ingest menu, and automatic checking is off until you turn it on.

0.2.1 · Latest0.2.00.1.0

Latest · September 20, 2026

0.2.1

The same Studio design, with more reliable Mac controls.

  • Select All works in the command palette, Settings, and sheets. Undo and redo stay in the field you are editing, even when its history is empty.
  • The palette keeps its search field still as results change. The footer shows the highlighted command and an Actions button for Pin/Unpin, Copy Link, and Configure Shortcut.
  • Inside the palette, ⌘K opens Actions. Escape closes Actions first, then the palette. Configure Shortcut takes you directly to the command in Settings.
  • Shortcut recorders support keyboard focus, Return or Space to start, and Escape to cancel, with named accessibility controls. Standard Mac editing keys stay protected.
  • Filename previews stay readable in Light appearance. Hints, hover states, focus rings, and floating-panel shadows adapt to appearance and accessibility display settings.
  • Accent controls update immediately when you choose a color. Archivo, the four accents, the black photo stage, and the existing layout are preserved.

0.2.0

A new look, and a receipt that tells you when the card can leave.

  • Ingest is set in Archivo, with one type scale across every screen. Filenames, paths, counts, and byte readouts stay in monospace, so the machine keeps speaking in one voice and people in another.
  • The inspector is sections rather than a stack of labels. The filename sits above a four-line block of what the camera recorded, and marks, stars, keywords, caption, and location each get their own space.
  • ⌘K groups results under headings. A command that cannot run keeps its place and prints the reason beneath it, so the list never shortens under the arrow keys.
  • Ingesting shows both of its stages at once. One band is what has come off the card; the solid band behind it is what has been read back, verified, and written under its final name. The card is safe to remove when the bar is one colour.
  • Each destination reports its own count, and a green tick appears only once that destination holds every file.
  • A run ends with a receipt: how many items, how fast, the first and last filename written, and what happened to the card.
  • When a run does not finish cleanly, the receipt says how many files exist only on the card and offers to ingest those. Retrying is always a choice, never automatic — a bad read is the clearest evidence a card is failing, and that is worth knowing rather than quietly working around.
  • Eject when done no longer fires if files were left behind. Ejecting is never blocked; the button is right there on the receipt.
  • Every commit sheet names its action and its count: Ingest 86 items rather than Ingest.

Memory cards are still never written to. Verification, the journal, and undo are unchanged — this release changes how the app looks and what it tells you, not what it does to your files.

0.1.0

The first release.

  • Browse a card or folder at full speed. Sony ARW and Fujifilm RAF are read through the JPEG the camera embedded, so photographs appear immediately and arrow keys never wait. JPEG, HEIC, and video work too.
  • Cull from the keyboard: tag, reject, five star ratings, and the Lightroom colour labels, all undoable. Compare two frames or survey four with the zoom locked across the panes.
  • Exposure brackets of three, five, seven, and nine frames are found and shown as one cell. RAW and JPEG pairs become one photograph, and both settings can be changed per folder.
  • Saved views in the sidebar with live counts, so a cull has a visible end. Workspaces carry a set of defaults for a kind of shoot and can switch themselves by camera model.
  • Ingest copies to one folder or two, reads each copy back and compares it to the source before publishing it, and never overwrites anything. Files leave a card only after their copies verified.
  • Name templates with the brace tokens and a sequence number that never repeats, with a preview of the real filenames before anything is written.
  • Keywords, captions, titles, ratings, colour labels, and GPS written into the files in the fields Lightroom and Apple Photos read, verified by reading them back. Quick entry sets all of it from one line.
  • Actions that run after a copy, an ingest:// URL scheme, and a settings file that carries your whole setup to another Mac.
  • Every command is in ⌘K, and every key can be changed in Settings.

Memory cards are never written to. That rule holds however a card was opened, and it is not a preference.
