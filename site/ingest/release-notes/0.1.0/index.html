What’s new in Ingest

Ingest 0.1.0

The first release.

  • Browse a card or folder at full speed. Sony ARW and Fujifilm RAF are read through the JPEG the camera embedded, so photographs appear immediately and arrow keys never wait. JPEG, HEIC, and video work too.
  • Cull from the keyboard: tag, reject, five star ratings, and the Lightroom color labels, all undoable. Compare two frames or survey four with the zoom locked across the panes.
  • Exposure brackets of three, five, seven, and nine frames are found and shown as one cell. RAW and JPEG pairs become one photograph, and both settings can be changed per folder.
  • Saved views in the sidebar with live counts, so a cull has a visible end. Workspaces carry a set of defaults for a kind of shoot and can switch themselves by camera model.
  • Ingest copies to one folder or two, reads each copy back and compares it to the source before publishing it, and never overwrites anything. Files leave a card only after their copies verified.
  • Name templates with the brace tokens and a sequence number that never repeats, with a preview of the real filenames before anything is written.
  • Keywords, captions, titles, ratings, color labels, and GPS written into the files in the fields Lightroom and Apple Photos read, verified by reading them back. Quick entry sets all of it from one line.
  • Actions that run after a copy, an ingest:// URL scheme, and a settings file that carries your whole setup to another Mac.
  • Every command is in ⌘K, and every key can be changed in Settings.

Memory cards are never written to. That rule holds however a card was opened, and it is not a preference.
