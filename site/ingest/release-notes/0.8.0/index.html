What’s new in Ingest

Ingest 0.8.0

Apple Photos is a source, not a second window

  • Choose Library, Favorites, Unfiled, Unreviewed, or any album in the sources list and the photographs swap in place. The sidebar width, the inspector, and the tab you were on stay where they were.
  • One set of commands covers files and Photos. A command that cannot apply says why rather than disappearing, and a shortcut you remapped applies in both places.
  • Turn Apple Photos integration off in Settings → General and the source is simply absent.

A photo bar you can read

  • Sort shows what the order is and turns it around with the button beside it. Sort by capture time, filename, rating, color label, date modified, or file size; Apple Photos adds album order and Organize adds group order.
  • Filter is a panel rather than a menu: what is shown, a minimum rating, any combination of color labels, and a kind such as brackets or video.
  • Everything you have chosen appears as chips under the bar, each with a cross, beside a count of how many photographs are showing and a Clear.
  • The search field is always visible, and a folder now reopens in the order you left it in.

Keywords are one pool

  • Settings → Keywords lists every tag with how many photographs carry it in Photos and in which folders, and sorts by any column.
  • Rename, merge, change case, unify spellings, or delete a tag everywhere at once, after a preview that says exactly what will change.
  • Fixes a merge into one of a tag's own spellings that removed the tag from the photographs in Apple Photos instead of keeping it.

New typography

  • Headings, photo names, and folder names are set in IBM Plex Sans. Filenames, exposure readouts, counts, and keyboard hints are set in iA Writer Mono, which is drawn from the same family.
  • Controls, captions, and hints stay in the macOS system font, so they match the menus and alerts the system draws.

macOS 15 or later, Apple silicon. Native Photos captions, keywords, and star ratings require macOS 27. Read the Photos guide.
