Cameras and files it reads

Ingest prefers an embedded camera preview or a paired JPEG / HEIF image. When a file needs RAW rendering, that slower first preview is handled separately and cached. Camera model and recording mode affect preview availability.

FileWhat happens
Sony .ARWUses available embedded previews, choosing the size needed for the current view.
Fujifilm .RAFReads the embedded JPEG where available.
.JPG and .JPEGReads the image and available embedded previews.
.HEIC, .HEIF, and .HIFOpens and browses.
.MP4 and .MOVBrowses and plays, with a poster frame in the grid. Sony clip sidecars travel with the file when you ingest.
Canon .CR2, .CR3; Nikon .NEF, .NRWEmbedded previews and metadata, including tested Canon CR3 files with HEIF previews.
Hasselblad .3FR, camera-origin .FFFEmbedded previews where available, with rendering fallback for files that need it. Scanner files and specialized multishot reconstruction are excluded.
Panasonic / Lumix .RW2; OM System / Olympus .ORFPreview and metadata support for tested camera samples.
Ricoh / Pentax .DNG, .PEF; Leica .DNG, .RWL, .RW2Preview and metadata support for tested camera samples.

Coverage is based on representative real camera files, not every recording mode. The sampled Nikon Z8 compression mode works through its embedded preview but fails in bundled LibRaw rendering. Native rendering succeeded on macOS 27; macOS 15 runtime remains unverified. Phase One, Sigma, scanner files, and specialized multishot reconstruction are outside this release.

XMP companions belong to their RAW photo and travel with it during file operations. Ambiguous companion groups remain separate.

Files that are never treated as photographs: sidecars such as .XMP and .THM, camera database and index files, and anything beginning with a dot.
