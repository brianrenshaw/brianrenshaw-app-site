Ingest/Support/A copy did not finish

A copy did not finish

Ingest copies to a temporary name, flushes it to disk, reads the copy back, compares it to the source, and only then gives it its real name. Nothing is ever overwritten. If something goes wrong part way, the files that were already copied and verified are kept and the rest are not, and the receipt records what happened.

The Import button is dim
The reason is printed beside it. The usual ones are no destination chosen, an empty All, Tagged, or Selected scope, a template that will not parse, or two photographs that would end up with the same name.
Names collide
Ingest refuses rather than quietly adding a suffix. Add {seqn} or {seq} to the template so every name is different. See collisions.
Not enough space
The import plan checks free space before it starts and tells you, rather than filling the disk and failing at photograph two hundred.
Deleting from the card
Keep Leave the card alone to preserve originals. If you choose Delete copied files, copies must verify at every destination. In a RAW-only import, cleanup also removes the intentionally excluded JPEG/HEIF twin after its RAW verifies. Changed, failed, or protected files are retained. Delete everything asks for confirmation and is not remembered for next time.

Find import progress

Import Progress opens automatically. Continue Browsing dismisses the panel without stopping the import. Use the photo-count/activity control to reopen it. Copy and verification are separate stages; later activity can continue after both bars finish. Check Import Complete or Import Needs Attention before disconnecting a drive.
