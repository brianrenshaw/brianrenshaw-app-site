Lightroom, a Shortcut, or an after-import action did not run

  1. Check the completion details for skipped or failed actions.
  2. Check each action’s Photos for this action scope. Importing All does not mean an action set to Tagged receives every file.
  3. Confirm the chosen app, Shortcut, or script is available on this Mac, and review any permission prompt.
  4. Retry unfinished actions from the result when offered. Successful actions are left alone.

Open an action in Settings → Automation and test it on a small disposable selection when appropriate. Opening files in an editor and importing them into that editor’s catalog are separate steps. After-import workflow · Automation reference.
