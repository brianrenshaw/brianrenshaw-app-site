Workspaces

Every kind of photography.
Your kind of workflow.

A weekend away and a client shoot do not need the same setup. Workspaces remember how you view, sort, and file your photos—and which tools you see.

Personal

Keep it simple. Keep a second copy.

Bring home the weekend’s photos. Keep the camera’s filenames, file them by date, and copy them to a backup destination at the same time. Add Apple Photos when it fits your personal workflow.

  • Original filenames
  • Dated folders
  • Verified second copy

Real Estate

One address. Everything in its place.

Enter the property address once. Use it in filenames, folders, and metadata. This setup keeps originals, HDR work, and final exports together under the address, with exposure brackets stacked for review.

  • Address-based naming
  • Folder structure
  • Exposure stacks

Wedding Photography

A setup for the whole wedding.

Keep each job organized, copy to a second destination, and route RAW and JPEG files where you need them. Review expressions with face close-ups and compare the moments that are almost the same.

  • Job folders
  • Face close-ups
  • RAW / JPEG routing

Landscape / Wildlife

Give the photograph your attention.

Use large previews to inspect detail and compare your favorites. Group bursts and similar scenes when it helps, choose your sort order, and hide tools you do not need for this shoot.

  • Large previews
  • Burst stacks
  • Flexible views

The Command Palette

Find it with ⌘K.

If you can do it in Ingest, you can find it with ⌘K. Search for what you want to do—from reviewing photos and editing metadata to organizing files and exporting. No need to remember where a tool lives or what its shortcut is.

Any action

What do you want to do?

Tag a keeper. Edit keywords. Change the sort order. Organize a folder. Start an export. Search for the action and run it from the same place. Available shortcuts appear beside commands.

  • Review
  • Metadata
  • Organize
  • Export

Switch workspaces

Change the setup with the shoot.

Find a workspace by name. Switch the view, visible tabs, favorites, and saved workflow settings together.

  • Personal
  • Real Estate
  • Wedding
  • Landscape / Wildlife

Find a folder

Your folders, a few letters away.

Find Folder searches your Mac and connected drives. Recent and favorite folders come first, so returning to a shoot starts in the same place as everything else.

  • ⌘K → Find Folder
  • ⇧⌘F

Show or hide tools

Make room for the photo.

Find the command to show or hide either sidebar. Ingest remembers sidebar visibility for each workspace.

The review tools

Move quickly.
Look closely.

Fast RAW previews and responsive keyboard controls keep the review moving. When a detail matters, take a closer look.

⌕

Close-ups and detail

Inspect faces and subjects, use the grid loupe, and zoom in to check focus.

◫

Compare and crop

Compare frames side by side with linked zoom. Crop and straighten in Preview.

▤

Scenes and stacks

Group similar scenes, review bursts, and keep exposure brackets together. Adjust groups when you need to.
