02 / Metadata Assist

Type ;.
See your options.

A structured editor, not an AI writer. Type ; and pick the field — Location, Caption, Keywords, or anything else — then Tab and fill it in. Changes show in a review panel first. Typing alone writes nothing. ; is for metadata fields; {…} is for rename and folder variables.
