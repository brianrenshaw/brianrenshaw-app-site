Map Location (GPS) searches for a place and previews its pin before Apply. It saves coordinates as well as IPTC place details. GPS coordinates are what photo apps such as Apple Photos and Lightroom use for a map location.

For proprietary RAW files, Ingest writes metadata to an XMP sidecar. Have your editor read the updated metadata. For Apple Photos, export a JPEG with metadata and GPS included; do not assume Photos reads a RAW sidecar. This is file metadata, not automatic cloud synchronization.

Optional IPTC fields, import templates, and TSV caption codes live in Metadata Assist when a job needs them. Use Edit Individual Fields for creator, copyright, and other IPTC details; import a local .ingesttemplate for reusable fills; type = for caption codes from a workspace TSV file.

Metadata Assist in the guide →

Choose Edit Individual Fields for optional IPTC details beyond Caption and Keywords, including creator, copyright, credit, and location fields. Use only the fields your workflow needs. Return the draft to Metadata Assist, review the proposed changes, and Apply.

Build reusable metadata templates with the fields you need. Import or export a local .ingesttemplate file in the metadata template editor, then choose a template in your workspace’s Metadata & actions settings.

Templates can replace values, fill empty fields, or add to supported lists. Review your template before using it on a job. Importing a template does not upload your photographs.

Add a UTF-8 TSV caption-code file to a workspace. Each row begins with a short code followed by tab-separated replacement text. Type = in Metadata Assist to find your codes; ; finds fields.

Enable Reload when code files change to pick up edits to those local TSV files. Keep a different vocabulary for each shoot, such as event names and venues. TSV files supply caption shortcuts; XMP sidecars store photograph metadata.

Press ⌘’ to open Metadata Assist. Type ; to see your field options — Location, Caption, Keywords, and the rest. A fragment like ;lo narrows the list. Choose a field, then fill the value or search for a place. Separate keywords with commas.

; finds metadata fields. Curly-brace tokens such as {client} are for rename and folder templates, not for Metadata Assist.

Metadata Assist guide →

Tab fills the highlighted field, code, or a value you have used before. Successfully applied or staged values stay in local history for recent-value menus, Tab completion, and Use Last Details. That history stays on this Mac.

In the demonstration: add Keywords landscape, waterfall, Yosemite, then replace the Caption Yosemite with Waterfall in Yosemite Valley.

Typing alone writes nothing. Changes appear in a review panel first. Check the proposed values against what is already on the photograph, then Apply. Cancel discards the draft.

Edit Individual Fields opens a detailed draft editor inside Metadata Assist; Use Changes returns that draft for review. Only Apply writes the reviewed changes.

Choose Camera & Lens… in Metadata Assist for film scans and other files that need equipment details. Pick saved gear from My Gear, search the offline catalog, or save a custom make and model.

Enter known aperture, shutter speed, ISO, and focal length; leave unknowns blank. Fill missing values preserves recorded metadata; Replace recorded values is for scanner metadata. Review Details returns to Metadata Assist before Apply. My Gear is local to this Mac.
