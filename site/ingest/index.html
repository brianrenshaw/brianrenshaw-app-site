01 / Workspaces

Set up the shoot once.
Forget the folders.

Workspaces are not just metadata presets. They remember the shoot setup — wedding, wildlife, headshots, personal — so you configure once and stop thinking about folder structure.

  • Metadata templates, folder structures, and renaming rules

  • Apple Photos and Social Export on or off for each workspace
  • Your starting view: grid, photo-first, or split

02 / Card to folders

From the card.
To your folders.

Open a card or a folder. Tag keepers with the keyboard. Ingest copies to your destinations and verifies the copies against the source. Keep Originals leaves the card untouched.

  1. Open. Card or folder. No catalog to build first.
  2. Decide. Your ratings, your calls.
  3. File. Destinations you choose. Copies verified.

Originals are kept by default. Source cleanup is a separate, explicit choice after verified copying. You can simply open a folder; no workspace setup required.

03 / Command Palette

Keyboard-first.
Never lost.

⌘K is the safety net and the teacher in one. Search an action, view, or mode. The shortcut appears beside it so you learn as you go.

Forgot the crop shortcut? Type “crop,” run it, and see the key.

Need more room? Find Hide Right Sidebar once; let muscle memory take over.

Want the photo front and center? Find Focus Mode, or press F to hide the surrounding controls. Press it again to restore them.

Looking for a folder? Search for Find Folder without leaving the keyboard.

04 / Metadata Assist

Write it once.
Review before it lands.

A structured editor, not an AI writer. One field per line, commas between keywords, and ; to find more fields. Recognized labels appear immediately in a review panel — no interpretation delay, no guessing from prose.

Every change is visible.

Correct values, inspect existing details, and choose Append, Replace, or Fill Empty where supported. Keywords append by default; other fields generally begin as replacements. Unrecognized lines and code errors stay visible for you to resolve.

Reuse what you already know.

Tab fills previously used values. Recent values recalls a field or a saved map location; Use Last Details loads the previous set for review. Caption codes expand known text, and Copy/Paste Metadata reuses selected groups.

A place name is not a map pin.

Location: Riverside Park adds descriptive text. Use Find place… and review the pin to prepare a GPS update with place details.

Details for the whole shoot.

Stage client, event, location, and shoot date for import naming and folders. Use for Import stages the details; copying is a separate action. Metadata goes to verified copies, and shoot date leaves camera capture times alone.

Projects retain shared details across cards; otherwise, choose Keep details for the next card. Explicit per-photo edits take precedence. Caption-code files and metadata-copy choices belong to your workspace.

Typing alone writes nothing. You review and apply; Cancel discards the draft. Metadata Assist does not invent captions, identify people, or interpret arbitrary instructions.
