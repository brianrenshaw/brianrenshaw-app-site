03 / Command-K

Know what you want to do?
Type it.

Press ⌘K, type an action, and keep going. No need to memorize every shortcut.

  • “review”

    Inspect a set of photos.

  • “sidebars”

    Clear space around the photo.

  • “focus peaking”

    Inspect fine detail.

  • “closed eyes”

    Find photos flagged for a closer look.

  • “subfolders”

    Look through nested folders.

Mac requirements

Requires macOS 15 Sequoia or later and a Mac with Apple silicon (M1 or newer). Intel Macs are not supported.

  • Apple Intelligence is optional. Text-based metadata assistance requires macOS 26 or later; suggestions generated from photographs require macOS 27.
  • Apple Photos: Editing captions, keywords, and native star ratings requires macOS 27. Other browsing and review features work on earlier supported versions.
