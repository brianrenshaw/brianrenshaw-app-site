Use a separate physical drive for Photo Backup. Ingest’s second verified copy is one part of a backup workflow: arrange off-site protection and editor/catalog backups separately. A Lightroom catalog backup does not back up your original photographs. See 3-2-1 backup guidance.

02 / Metadata Assist

Type ;.
See your options.

A structured editor, not an AI writer. Type ; and pick the field — Location, Caption, Keywords, or anything else — then Tab and fill it in. Changes show in a review panel first. Typing alone writes nothing. ; is for metadata fields; {…} is for rename and folder variables.

  1. Find a field. Open Metadata Assist, type ; and search Location. Choose IPTC Place Shown and enter Yosemite Valley.
  2. Add the details. Add Keywords: landscape, waterfall, Yosemite. Replace the Caption Yosemite with Waterfall in Yosemite Valley.
  3. Review, then Apply. Check the proposed changes and the existing caption. Click Apply to 1 Photo; the saved caption, keywords, and place appear beside the photograph.

A place name describes the photo; it doesn’t change its GPS coordinates. Pause or open fullscreen to take a closer look.
