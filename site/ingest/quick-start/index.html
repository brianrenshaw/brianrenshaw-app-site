Ingest / Quick start

Start with a card. Or any folder.

Open your photos, review what matters, and choose where they go. Start with original filenames and a simple destination; add a workspace whenever you want to save a setup.

  1. Before you start

    Ingest needs macOS 15 or later on an Apple silicon Mac. Have a card in the reader, or a folder of photographs. Ingest supports the major camera RAW families, JPEG, HEIC / HEIF / HIF, and existing video formats. Check the support page for camera formats and recording-mode limitations.

    No account, nothing to install alongside it. If you would rather practice on something that cannot matter, choose Help, then Open Practice Folder.

  2. Open the card

    Put the card in. It appears in the sources list on the left. Ingest opens cards automatically by default; you can change that in Settings → General. For a folder instead, press ⌘O.

    Ingest loads embedded previews where available, so you can start reviewing while the rest of the folder is read. Speed depends on the files and storage. How browsing works →

  3. Look at them

    Arrow keys move. Space opens the big view and Space closes it. Z goes to 100% under your pointer, and Z again comes back.

    Press I in the preview for the exposure. C puts two frames side by side with the zoom locked together. The preview.

  4. Decide

    One key each. T toggles a tag. U removes it. 1 to 5 are stars, 6 to 9 are the Lightroom colors. ⌘Z undoes any of it.

    The counts in the sources list move as you go, so you can see how much is left. If you would rather each key moved you on to the next photograph, that switch is in Settings, Culling. Culling.

  5. Deal with the brackets

    If you shoot exposure brackets, recognized sets appear as one cell with a badge. S opens the set you are on, ⌥S opens all of them, and tagging a closed set tags every frame in it. Stacks.

  6. Describe them, if you want to

    Optional, and skippable entirely. Press Q and type one line: coast sunrise 3* "First light at the pier". Keywords, a rating, and a caption in one go. ⌘L looks up an address and attaches the location.

    Nothing is written to the card. Ingest remembers it and writes it into the copies. Metadata.

  7. Say where they go

    Press ⌘G to open Ingest. Choose your source and workspace. The right sidebar shows the saved destinations and naming rules. Use Change for This Import to adjust this job without changing the saved workspace.

    Start with original filenames and a dated folder, with an optional second destination for a backup copy. If you need custom names, use a naming template and check the resulting filenames in the destination preview. Naming options →

  8. Ingest

    Use the checkboxes to include the photos you want to import. Check All and Uncheck All set a starting point. Review the file count, folders, filenames, and destinations, then click Ingest or press ⌘↩.

    Each file is copied, read back, compared to the original, and only then given its real name. Nothing is ever overwritten. Files are removed from the card only if you asked, and only the ones that verified. What happens during an ingest.

  9. Afterwards

    Review the completion receipt to confirm what copied and whether anything needs attention. Open the destination to browse the results. Return to Browse and press ⌘E when you are ready to eject the card.

    For your next card, return to Ingest and review the saved setup. You can also browse and organize an existing folder without importing it first.

Already using Apple Photos?

Choose Apple Photos in the sidebar to connect your System Photo Library, review photos, and organize ordinary albums. Or select files after ingest and choose Send to Apple Photos… to review a JPEG-first import. The integration is on by default; Settings → General can turn it off. Workspace-specific control is planned. Read the Photos guide →
