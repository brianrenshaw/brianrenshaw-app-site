# Ingest assets

Icon: exported from the native Ingest AppIcon asset.

Screenshots: unmodified captures of the Mac app running against a demonstration memory card. The card is a disk
image holding 24 JPEG frames with Sony EXIF written onto them, including a five shot and a three shot auto bracket
set so the stacking behaviour in the captures is real. No client work and no personal photographs appear anywhere.
