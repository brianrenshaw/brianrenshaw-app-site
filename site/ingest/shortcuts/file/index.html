Ingest/Keyboard shortcuts/Files and ingest

Files and ingest

⇧⌘E opens Send to Decks… for selected still photos. Choose Decks for Mac or system sharing to iPhone or iPad; choose a new or existing project in the receiving app. Browse keeps ⌘E for Eject. Composition and export shortcuts belong to Decks.

KeysCommand
⇧⌘ESend to Decks…
⌘EEject a card in Browse
⌘OOpen a folder
⌘GOpen Import Settings
no default keyReview the selection or visible photo queue; configurable in Settings
⌘WClose the current Browse tab, or the focused idle editor window
⌘YCopy to a folder, without the rest of the ingest machinery
⌘RRename photographs where they are
⌥⌘RRe-sequence what is shown, so the numbers have no gaps after a cull
⇧⌘RReveal in Finder
⇧⌘FFind Folder in the Command Palette; search folder names and open a result without replacing the sidebar tree
⌘Z ⇧⌘ZUndo and redo
no keyClose the source
