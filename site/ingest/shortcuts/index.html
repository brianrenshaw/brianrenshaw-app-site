Ingest / Shortcuts

Find it with ⌘K. Make it your own.

Search for anything you want to do in Ingest. The Command Palette gives you access to app actions without memorizing shortcuts. Learn the keys you use most and customize them in Settings.

How to read this

⌘ is Command, ⌥ is Option, ⌃ is Control, and ⇧ is Shift. A key written on its own, like T, is pressed on its own.

Some keys mean different things depending on where you are. In the file browser, there are three places: the grid of thumbnails, the large preview, and a video playing in the preview. Where a key only works in some of them, the table says so. Apple Photos and Social Export have their own contextual commands.

Single letters pause whenever you are typing. If the cursor is in the keyword field, T types a letter t. Press Esc to leave the field and the keys come back.

A command that cannot run right now does not fail quietly. It beeps and the status bar says why, for example that nothing is tagged, or that the source is read only.

Changing a key

Open Settings, then Shortcuts. Every command is listed with its key. Click the key and press the one you want. You can also Tab to the recorder and press Return or Space to begin. Esc cancels, and Delete removes the key so the command has none.

If the key is already taken by something that overlaps, Ingest names the other command and offers to move the key across. It refuses a key that is fixed, and it refuses the bare keys that move you around, because the app consumes those before any command sees them.

Standard Mac editing keys are reserved. Select All, Undo, Redo, and Settings retain their native shortcuts. If an older custom binding conflicts with a standard key, Settings explains the conflict and offers a reset; the saved override is kept until you change it.

While a text field has focus, ⌘A selects its text, and undo and redo stay in that editor. Photo-navigation keys do not intercept typing.

A changed key follows everywhere at once. The menus, the palette, the ? sheet, and the hold overlay all read from the same table, so there is no second place to update and nothing to get out of step. Reset All puts every key back.

Every action, one search

Find Source Summary, Select from Pick List, Export Selected Decisions, and Open Current Source in New Tab by name. Source Summary opens in the inspector; clicking a count applies a removable filter.

If you can do it in Ingest, you can find it with ⌘K—whether the action has an assigned shortcut or not. Press ⌘K and search by name, alias, or category. Switch workspaces, find a folder, tag a keeper, edit metadata, organize files, or export without navigating menus.

Inside the palette, ⌘K toggles Actions. Use the arrow keys and Return to choose Pin/Unpin, Copy Link, or Configure Shortcut. Esc closes Actions before it closes the palette. Configure Shortcut reveals that command in Settings; temporary card and recent-folder entries do not offer it.

The palette also lists the things that come and go: your favorites, workspaces, splits, metadata presets, actions, and recent folders. ⇧⌘P pins whatever is highlighted to the top of the list. ⇧⌘C copies a link that runs it, which is how the URL scheme is meant to be discovered.
