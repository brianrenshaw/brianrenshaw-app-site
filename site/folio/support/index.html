Adding pages

Tap + in the Library and choose one of four options:

  • Import a File for a single HTML file.
  • Import a Folder as One Page when a page needs the CSS, JavaScript, images, or data stored beside it.
  • Watch a Folder for Pages to keep the HTML files in a chosen folder current automatically.
  • Add from Google Drive to choose a file using Google's secure sign-in and picker.

You can also send an HTML file to Folio from another app's Share sheet.

Google Drive

Use + → Add from Google Drive to sign in and choose a file. Folio can later refresh selected Drive pages without changing the originals. Drive is optional, and Folio works fully without it. To revoke access and remove the locally stored connection, open More (…) → Settings → Disconnect Drive. See the Privacy Policy for details.

Removing a page

Swipe left on a page in the Library and tap Remove. This removes Folio's copy but leaves the original file alone. A watched-folder page can return the next time Folio checks its source; remove the watched folder if you no longer want its pages in the Library.

Organizing the Library

Touch and hold a page, or swipe left and tap …, to open Page Settings. You can rename it, add tags, choose an emoji or symbol, mark it as a favorite, control network and iCloud options, or require Face ID or the device passcode. Use the filter control above the Library to sort, group, and filter your pages.

Network access

Pages are offline by default. To let one page contact addresses contained in its own code, open Page Settings and enable Network Access for that page.

iCloud sync

Open More (…) → Settings and turn on Sync with iCloud to keep library information consistent across your devices. Include Page Files and Include App Settings are separate choices. You can also keep an individual page off iCloud in its Page Settings.

Locking a page

Touch and hold a page and choose Require Face ID, or use the Privacy control in Page Settings. Folio falls back to the device passcode when needed. Locked pages are protected when opened from Folio, widgets, or Home Screen quick actions and are shielded in the app switcher.

iPad workspace

On iPad, Folio can show the Library, page list, and reader together. Select a page to open it in the workspace, or use the reader's focus control when you want the page full screen.

Widgets and quick actions

Add a Folio widget from the Home Screen widget gallery, then touch and hold it and choose Edit Widget to select a page. Touch and hold the Folio app icon to open favorite and recent pages directly.

PDF export

Open a page and use its … menu to print or save and share a PDF.

Appearance

Open More (…) → Settings to choose light, dark, or system appearance, an accent color, toolbar positions, and default zoom.

Starting over

More (…) → Settings → Reset Everything removes Folio's pages and watched folders and restores the app's settings. It does not delete original files from Files, watched folders, or Google Drive. A page that exists only as Folio's imported copy cannot be recovered after the reset.
