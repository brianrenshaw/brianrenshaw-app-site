Import recipe photos with your own AI

Use ChatGPT, Claude, Gemini, or an AI agent to transcribe recipe photos. You choose which photos to share. Your AI provider’s privacy terms apply.

iPhone and iPad

  1. Open Add › Import with Your AI › Choose Photos. Select the card photos in order, front before back.
  2. Tap Copy Prompt, then Share Photos. In your AI chat, paste the prompt and send it with the photos.
  3. Copy the entire reply. Return to Faded Recipes and tap Paste to import the recipes with their photos.

Mac

  1. Put the photos in one folder. Open File › Import with Your AI and choose Copy Prompt.
  2. Attach the photos to your AI chat and paste the prompt. Save the reply as faded-import.json in the photos folder. If you use an AI agent with file access, give it the folder and prompt so it can save the file for you.
  3. In Faded Recipes, select Choose Folder and import the recipes. To import the same folder on iPhone or iPad, open Import with Your AI › Use a Folder Instead.
View the Mac import prompt 
I'm importing handwritten and printed recipe cards into Faded, a recipe app. Read every photo of a recipe in the folder I point you to. Use each photo's exact file name.

Transcribe each recipe exactly as it is written. This is copying, not cooking:
- Copy every word, abbreviation, amount, fraction, unit, oven temperature, and time as written ("1/2 c. oleo", not "1/2 cup margarine"). Keep the writer's spelling.
- Never add, complete, correct, or guess an ingredient, amount, or step. If something can't be read, write [unclear] in its place.
- One ingredient per line, in the order written, with its amount and preparation. Put a heading written over a group of ingredients ("Filling") in "section".
- A food measured only inside the directions goes at the end of the ingredients.
- Steps in order, wrapped lines joined. Notes are any other handwritten remarks.
- Make the capitalization consistent, whatever the card did (all capitals included):
  - Titles and section headings in title case: "Tempting Apple Crisp", "Topping".
  - Ingredient lines in lowercase: "1/2 c. firmly packed brown sugar". Keep brand and proper names capitalized ("Rice Krispies", "Crisco", "Grandma's"). Keep every unit abbreviation exactly as written, because its case can be its meaning: "T." is a tablespoon and "t." a teaspoon, so never change "1 T. butter" to "1 t. butter".
  - Steps and notes in sentence case: "Bake at 375° for 30 minutes."
  Capitalization is the only thing to change; keep the words, spelling, and abbreviations.
- Leave out printed form captions such as "Recipe from the kitchen of" unless something is handwritten after them.
- When several photos show one recipe (front and back, or two pages), make one recipe that lists all of them, front first. When one photo holds two recipes, make two recipes that both list it.
- Skip photos that aren't recipes.
- If you can rename files, rename each photo after its recipe's title in lowercase with hyphens, keeping its extension: "tempting-apple-crisp.jpg", then "tempting-apple-crisp-2.jpg" for a second photo of the same recipe. List the new names in "photos". If you can't rename files, list the names as they are.

Write the result as JSON in exactly this shape, and nothing else. When you can write files, save it as faded-import.json in the same folder as the photos.

{
  "format": "faded-import",
  "version": 1,
  "recipes": [
    {
      "photos": ["apple-crisp.jpg", "apple-crisp-2.jpg"],
      "title": "Apple Crisp",
      "from": "Grandma Ruth",
      "servings": 6,
      "yield": "",
      "prepMinutes": 0,
      "cookMinutes": 30,
      "totalMinutes": 0,
      "ingredients": [
        { "section": "", "line": "4 c. sliced apples" },
        { "section": "Topping", "line": "1/2 c. brown sugar" }
      ],
      "steps": ["Place apples in shallow baking dish.", "Bake at 375° for 30 minutes."],
      "notes": ""
    }
  ]
}

Use "" or 0 for anything the card doesn't say.

Review imported recipes

Open recipes marked Check and compare them with the photos. Look for [unclear] where the AI couldn’t read a word or amount. If a photo is missing, check that its filename matches the one in faded-import.json.

Restore an exported library

Choose Import with Your AI and select the folder saved by Export Library. It already contains the recipes and photos.
