Walkthrough help/Edit listing photos

Add pins, labels, arrows, and a compass

Annotate a photo in the outline editor and look up nearby places with Apple Maps.

On this page
Choose a markerPosition and style a markerFind a placeSave the annotated photo

Choose a marker

Select a photo and open Outline Property with ⇧⌘O. The editor can save markers without a property line.

  • Home: mark the listing with a home pin.
  • Pin: mark a spot on the photograph.
  • Callout: add a text label. The inspector offers styles including a label at the edge of the photo for a place outside the frame.
  • Arrow: point toward a feature or direction.
  • Compass: add a compass rose and adjust its north direction.

Choose a tool from the editor bar, then click to place it. You can also right-click on the canvas to add markers. The On the photo list helps you select existing markers.

Position and style a marker

Drag a marker to move it and a corner to resize it. Use the rotation ring on arrows, edge labels, and the compass to change their direction. Edit text and available style controls in the inspector. A label can have a leader line pointing at a specific spot.

Compass direction can use a drone-heading suggestion when the original photo contains one. Check and adjust it for the image you are annotating.

Find a place

Add the listing address, select a label or pin, and use Find Place in its inspector. Search Apple Maps and choose the correct match. Walkthrough can include the place name and an estimated driving or walking time from the listing, with an optional distance.

Search and route estimates need an internet connection. Times are Apple Maps estimates by road. An off-frame label indicates a direction you place on the image; it is not a surveyed map location.

Save the annotated photo

Choose Save Outline. Markers are rendered into the JPG copy, and their editable settings stay with the local job. Select that copy and choose Edit Outline to adjust them later. For several destinations at once, use Nearby Places.
