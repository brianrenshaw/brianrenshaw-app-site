Walkthrough help/Edit listing photos

Build a nearby-places list

Search a list of destinations, review travel estimates, and copy text or add it to a photo.

On this page
Add the listing addressSearch and review placesCopy a list for a descriptionAdd places to a photo

Add the listing address

Check the address in Listing Details, then choose Nearby Places in the inspector or find it with Command-K. The address is the starting point for travel estimates.

Search and review places

  1. Paste or type place names, one per line.
  2. Choose Search All. Walkthrough searches Apple Maps near the listing address.
  3. Check each result. If the first match is wrong, choose another match from the place’s menu.
  4. Review the driving and walking estimates. Retry an unresolved search or remove an entry you do not need.

A place can be found even when a route is unavailable. Check the address and match before using the result. Search and route requests require an internet connection, and Apple Maps travel times are estimates rather than guarantees.

Copy a list for a description

Use Drive, Walk, and Distance to choose what appears in the text preview. Select a list style, then choose Copy to put the text on the clipboard. Paste it into your listing description or other document. Walkthrough does not publish the listing.

Add places to a photo

Open a photo in the outline editor, then choose Nearby in its tool bar. Add as Card puts the resolved places in one card. Add as Callouts adds separate labels that you can position on the photo.

The photo card and callouts use driving times when Drive is selected; otherwise they use walking times when Walk is selected. Distance follows your selected setting. These buttons are available only while an outline is open and at least one place has been resolved.

Position the card or labels, then choose Save Outline. The list and selected matches stay in this Mac’s job library. See Privacy for the information sent to Apple Maps.
