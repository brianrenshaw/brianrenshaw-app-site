Keyboard reference

Find shortcuts for selection, preview, grouping, ordering, and processing.

⌘ is Command, ⌥ is Option, and ⇧ is Shift. Photo shortcuts apply when the workspace owns focus. They pause while you edit text, use focused controls, or work in a dialog. Command-A keeps its normal Select All behavior in text fields.

KeysAction
⌘KOpen command palette
⌘OOpen a photo folder
⌘RRefresh photos from disk
⌘DeleteMove selected photos to macOS Trash
⌘A / ⇧⌘ASelect all photos in the current room or scope / show and select all ungrouped photos
G / UChoose a group / return selected photos to Ungrouped
⇧GOpen group-order editor
⌥⌘← / ⌥⌘→Move selected photos earlier / later
Space / ZToggle Preview / toggle Fit and 100% zoom
TChoose a template
⌘1 … ⌘9Apply the first nine naming presets in library order
⌥⌘1 / ⌥⌘2 / ⌥⌘3Contact Sheet / Preview / Split
⌥⌘IToggle inspector
E / ⇧⌘EOpen Process Photos
⌘Z / ⇧⌘ZUndo / redo workspace changes
⌘,Open Settings
⌘N / ⌘TOpen a new job tab
⌘WClose the current tab or Settings window
?Open shortcut help

Move Earlier/Later works when all selected photos belong to one group or to Ungrouped. Each selected run moves one position while keeping its internal order. Moves stop at section boundaries, never cross groups, and each successful invocation is one undo step. In All Photos, Select All also includes photos in collapsed groups. In one room, it selects only that room’s photos.
