A record of what’s new.

New features, refinements, and fixes for preparing listing photos. Find this history anytime from Help → Release Notes or Settings → General in the app.

Latest

1.4.2

Process Photos and a visual Getting Started guide

  • The photo workflow is now called Process Photos, covering Rename only, Copy, and Move. Settings-file export keeps its name.
  • A pinned Process X Photos button at the bottom of the inspector shows every included photo in the job. The review dialog confirms the exact operation and ready count.
  • Getting Started now has five steps with current app screenshots, detail and full views, enlargement, and persistent navigation.
  • Settings rows adapt to available space, with clearer selected controls and grouped fields.

Existing jobs, presets, shortcuts, and original JPG bytes remain compatible. Use Walkthrough → Check for Updates to install this release.

1.4.1

A more natural Mac experience

  • Settings save valid edits automatically, with a clear saved status, inline shortcut validation, and Retry if saving fails. Closing Settings or quitting waits for pending saves and protects unfinished edits.
  • System typography and native Settings surfaces improve readability and consistency. The photo canvas stays dark and filenames remain readable in Light appearance.
  • The command palette has softer shadows, clearer selection, and a footer that names the action Return will perform. Home suggestions offer opening a folder, Settings, help, and recent jobs.
  • Text editing keeps familiar Mac behavior, including Command-A, copy and paste, Undo, and Tab navigation. Photo focus no longer interrupts an active text field.
  • Refined contrast, transparency, and reduced-motion behavior, plus clearer export progress descriptions for accessibility.
  • A new teal house-and-number app icon matches Walkthrough’s default accent. Amber, Sky, and Clay remain available in Settings.

Existing jobs, presets, templates, and photo files remain compatible. Use Walkthrough → Check for Updates to download and install this release.

1.4.0

One design language, and an export you can watch

  • Walkthrough is set in Archivo, with one type scale across every screen. Filenames, paths, and counts stay in monospace, so the machine keeps speaking in one voice and people in another.
  • The window is built from four planes separated by hairlines, and the title bar dissolves into the toolbar. Selected photos take an accent ring instead of system blue, and Settings lets you choose the accent.
  • The inspector is three sections about one photograph rather than a settings form. Address fields show which one has the keyboard, and the filename preview is colored piece by piece with the preset named underneath, so the preview cannot drift from the name that gets written.
  • Command-K keeps every result in its place while you arrow through the list.
  • Sheets share one shape, and each primary button names its count — Rename 100 rather than Rename — so the number is there to check before you commit.
  • Exporting no longer waits behind a spinner. The sheet closes when the run starts and a progress strip takes the bottom edge of the window: one band for photos staged, a solid band behind it for photos written under their final name.
  • Arrow keys hand off between the room list and the photographs. Right steps into a room, and Left at the first photo steps back out.

Rename only, Copy, and Move are unchanged, as are export collision checks, verification, and recovery. Existing saved jobs remain compatible. This release changes how the app looks and what it tells you, not what it does to your files.

1.3.0

Keep your photo folder current and finish exports with fewer interruptions

  • Added, deleted, renamed, and edited photos update automatically while a job is open. Refresh Photos (Command-R) checks immediately, while existing photos keep their room assignments and order.
  • Exclude photos from a job without deleting them. The Excluded sidebar view lets you include them again; Include and Exclude support Undo.
  • Reveal selected photos in Finder or move them to macOS Trash with Command-Delete. These actions support multiple photos from the Photos menu, command palette, and right-click menu.
  • Export now separates naming warnings from file errors. Enable Skip photos with errors to process valid photos while leaving problem photos for later. Ready, skipped, and total counts explain what will happen.
  • Needs Attention keeps skipped photos, their error details, and their intended filenames. Retry Selected previews and processes just the failed photos after you fix the problem.
  • Improved thumbnail refresh, source-file checks, and recovery after partial exports. Previewed numbering stays fixed when photos are skipped, and existing destination files are never overwritten.

Rename only still changes filenames in place. Copy and Move keep their existing destination and group-folder choices. Existing saved jobs remain compatible.

1.2.3

Native tabs and a tidier job list

  • New Job (Command-N) and New Tab (Command-T) open native macOS tabs, keeping the current job open. Close the selected tab with Command-W.
  • Remove jobs from Recents using the × button, right-click menu, or folder menu. Saved rooms and photo order are kept and return when you reopen the folder.
  • Fixed “No JPG photos” persisting when a previously empty saved folder now contains photos.
  • A Home toolbar button returns to your recent jobs, and Export has a clearer icon.

1.2.2

A smoother workflow for larger photo jobs

  • More responsive address typing, photo selection, keyboard navigation, scrolling, and pane resizing. Filename captions update without rebuilding the photo grid.
  • Faster export previews check paths in the background, keeping the window responsive while you review a large job.
  • Job loading, folder checks, and saving run in the background. Recent jobs use less memory while keeping your saved history.
  • Previews fit the pane and prioritize nearby photos in the room you are browsing. Improved image caching reduces memory use and prevents an old photo appearing under a new filename.
  • Faster command search and background Settings file import and export.

Existing jobs, filenames, photo order, and original JPG quality remain compatible. Exports retain collision checks, verification, and recovery safeguards.

1.2.1

Reliable room names and business filenames

  • Fixed choosing a room preset with the keyboard creating an “Untitled Room,” including after reopening the app.
  • “With Business” uses your current saved business profile when applying presets or templates and reopening jobs.
  • Blank or unusable filename-name overrides fall back to the business name. If no usable business name is configured, the filename preview explains where to add one.
  • Reopened jobs pick up matching tag renames while preserving manual room names, template overrides, historical tags, and custom filename formats.

Existing jobs remain compatible. Reopening a job updates filename previews; photo files change only when you export.

1.2.0

A native room workspace

  • Browse All Photos, Ungrouped, or one room in a native sidebar. Selection, navigation, and the preview filmstrip follow the room you choose.
  • Use a simpler native toolbar, resizable split panes, and a form-based inspector. Compact group headers and single filename captions give the photos more space.
  • Command-K opens a centered palette. Choose Change Group Name to rename the selected photo’s group, with the current name filled in and Command-Z support.
  • Settings uses vertical filename-building rows and native controls. Export All Photos clearly reviews the entire job in a table with resizable path columns.
  • New installations follow the Mac’s appearance; saved appearance preferences are preserved.
  • Updated Getting Started, keyboard help, and the illustrated website guide cover the new workflow. The guide index no longer overlaps content while scrolling.

1.1.0

A faster keyboard workflow. More ways to deliver.

  • Open the command palette with Command-K. Search actions, groups, tags, naming presets, templates, and recent jobs, with shortcuts and explanations when an action is unavailable.
  • A quieter native title bar brings view switching, Commands, the inspector, and Export together.
  • Command-A selects every photo, including collapsed groups. Shift-Command-A selects ungrouped photos. Option-Command-Left/Right moves selected photos earlier or later within their section.
  • Choose Rename only, Copy, or Move during export. Copy and Move can create numbered group folders in the current folder or a new destination, with complete output paths to review.
  • Reopen jobs after folder exports and repeat Copy or Move exports. Conflicting paths are blocked without overwriting files.
  • Refreshed, resizable Settings includes aligned editors, clearer shortcut validation, and a persistent Save Settings area. Appearance and update preferences still apply immediately.

  • Improved Split view in narrower windows.
  • Added a replayable six-step introduction to grouping, ordering, naming, and exporting photos.

Existing jobs, presets, and settings remain compatible.
