Walkthrough / Release notes

A record of what’s new.

New features, refinements, and fixes for preparing listing photos. Find this history anytime from Help → Release Notes or Settings → General in the app.

1.2.3 · Latest1.2.21.2.11.2.01.1.01.0.21.0.11.0.0

Latest

1.2.3

Native tabs and a tidier job list

  • New Job (Command-N) and New Tab (Command-T) open native macOS tabs, keeping the current job open. Close the selected tab with Command-W.
  • Remove jobs from Recents using the × button, right-click menu, or folder menu. Saved rooms and photo order are kept and return when you reopen the folder.
  • Fixed “No JPG photos” persisting when a previously empty saved folder now contains photos.
  • A Home toolbar button returns to your recent jobs, and Export has a clearer icon.

1.2.2

A smoother workflow for larger photo jobs

  • More responsive address typing, photo selection, keyboard navigation, scrolling, and pane resizing. Filename captions update without rebuilding the photo grid.
  • Faster export previews check paths in the background, keeping the window responsive while you review a large job.
  • Job loading, folder checks, and saving run in the background. Recent jobs use less memory while keeping your saved history.
  • Previews fit the pane and prioritize nearby photos in the room you are browsing. Improved image caching reduces memory use and prevents an old photo appearing under a new filename.
  • Faster command search and background Settings file import and export.

Existing jobs, filenames, photo order, and original JPG quality remain compatible. Exports retain collision checks, verification, and recovery safeguards.

1.2.1

Reliable room names and business filenames

  • Fixed choosing a room preset with the keyboard creating an “Untitled Room,” including after reopening the app.
  • “With Business” uses your current saved business profile when applying presets or templates and reopening jobs.
  • Blank or unusable filename-name overrides fall back to the business name. If no usable business name is configured, the filename preview explains where to add one.
  • Reopened jobs pick up matching tag renames while preserving manual room names, template overrides, historical tags, and custom filename formats.

Existing jobs remain compatible. Reopening a job updates filename previews; photo files change only when you export.

1.2.0

A native room workspace

  • Browse All Photos, Ungrouped, or one room in a native sidebar. Selection, navigation, and the preview filmstrip follow the room you choose.
  • Use a simpler native toolbar, resizable split panes, and a form-based inspector. Compact group headers and single filename captions give the photos more space.
  • Command-K opens a centered palette. Choose Change Group Name to rename the selected photo’s group, with the current name filled in and Command-Z support.
  • Settings uses vertical filename-building rows and native controls. Export All Photos clearly reviews the entire job in a table with resizable path columns.
  • New installations follow the Mac’s appearance; saved appearance preferences are preserved.
  • Updated Getting Started, keyboard help, and the illustrated website guide cover the new workflow. The guide index no longer overlaps content while scrolling.

1.1.0

A faster keyboard workflow. More ways to deliver.

  • Open the command palette with Command-K. Search actions, groups, tags, naming presets, templates, and recent jobs, with shortcuts and explanations when an action is unavailable.
  • A quieter native title bar brings view switching, Commands, the inspector, and Export together.
  • Command-A selects every photo, including collapsed groups. Shift-Command-A selects ungrouped photos. Option-Command-Left/Right moves selected photos earlier or later within their section.
  • Choose Rename only, Copy, or Move during export. Copy and Move can create numbered group folders in the current folder or a new destination, with complete output paths to review.
  • Reopen jobs after folder exports and repeat Copy or Move exports. Conflicting paths are blocked without overwriting files.
  • Refreshed, resizable Settings includes aligned editors, clearer shortcut validation, and a persistent Save Settings area. Appearance and update preferences still apply immediately.

1.0.2

Clearer from the first launch.

  • Updated the welcome screen and Getting Started guide to focus on renaming and ordering files for MLS uploads, listing websites, and client delivery.
  • Refined the house icon with a simple numbered label.
  • Added Release Notes to the Help menu and Settings, with a permanent update history on the website.

1.0.1

Listing Namer is now Walkthrough.

  • Redesigned the workspace with numbered room sections, larger thumbnails, clearer selections, and separate grouping and naming controls.
  • Made dark appearance the default for new installations, while keeping existing appearance preferences.
  • Improved Split view in narrower windows.
  • Added a replayable six-step introduction to grouping, ordering, naming, and exporting photos.

Existing jobs, presets, and settings remain compatible.

1.0.0

The first public release, as Listing Namer.

  • Organize JPGs in Contact Sheet, Preview, and Split views.
  • Group and reorder photos with keyboard shortcuts, then preview consistent filenames.
  • Save jobs locally and export without changing the original JPG quality.
  • Check for updates from inside the app.
