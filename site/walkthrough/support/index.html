Walkthrough / Support

Help with folders, naming, and processing.

Walkthrough opens folders of JPG or JPEG files for grouping, ordering, and filename processing. Photos directly inside the selected folder appear in the contact sheet. Jobs and naming choices save automatically on this Mac.

Getting started

A five-step screenshot introduction opens the first time you launch the app. Finish it or choose Dismiss. To see it again, choose Help → Getting Started, or use Getting Started on the welcome screen. Replaying the guide leaves your current job untouched.

How numbered filenames sort

Keep related photos together, put groups in your preferred listing order, then arrange the photos within each group. Sorting the processed files by name, ascending, follows that sequence. Check the final photo order in the MLS or website after uploading.

The Standard format produces 123-Oak-St_01_Entry-02.jpg: the address, room number, room name, and photo number. The room number keeps groups together; the photo number orders the views inside each group.

Leading zeros matter: 01, 02, … 10 stay in numeric order during text sorting, while 1, 10, 2 can appear out of sequence. Room and photo numbers use two digits by default.

Browse your rooms

Choose All Photos, Ungrouped, or one room in the sidebar. Selection, arrow navigation, and the preview filmstrip follow that scope. Toolbar buttons switch Contact Sheet, Preview, and Split; drag pane dividers to adjust their widths. The inspector holds selection actions, naming, and listing details, with a pinned Process X Photos button at the bottom. Its count includes the whole job, regardless of the selected room or photos.

Choose a group

Select photos and press G. Type to find an existing group, or type a new name and choose Create. Use Up and Down to highlight a result, Return to apply, and Escape to cancel. The inspector’s Add to Group button opens the same picker. You can also drag photos onto a room in the sidebar.

Rename a group

Select one of the group’s photos, press Command-K, and search Change Group Name. Replace the filled-in name and press Return. For example, rename Garage to Outside Garage. The group label and filename previews update together; Command-Z undoes the change. Escape cancels. Select photos from only one group, or choose the room in the sidebar. See the illustrated rename example.

Change the delivery order

Drag rooms in the sidebar, use the room’s context menu, or press Shift-G. Use Up/Down to choose a group, Option-Up/Down to move it, or P to enter a position. Apply Order renumbers the filenames. Command-Z undoes the whole change.

Photos changed or need removing?

Open jobs update when files change in Finder. Use Refresh Photos (Command-R) to check immediately. Exclude from Job keeps a file on disk; restore it from the Excluded sidebar view with Include in Job. Reveal in Finder and Move to Trash (Command-Delete) work on selected photos. See folder changes and removal.

Process

Process Photos includes all active photos in the job, even when you are viewing only one room. It always opens with Rename only selected. Choose Copy or Move to use the current folder or another destination, with optional numbered group folders. Review the output paths and acknowledge naming warnings. Enable Skip photos with errors to process ready photos and leave problem files in Needs Attention, where Retry Selected uses their retained filenames. Job-wide problems such as an unavailable destination still block processing. Copy keeps the source files; the open job follows the processed files after either Copy or Move. See the processing guide and examples. JPG bytes remain unchanged; thumbnail resizing only changes the display.

Settings save automatically

Open Settings with Command-comma. Valid changes to tags, presets, templates, and your business profile save automatically. The footer confirms when everything is saved. Correct invalid shortcuts or choose Retry after a save error; your edits remain available. Command-A selects text in the active field, and standard copy, paste, undo, and Tab navigation work while editing.

Availability and updates

Walkthrough requires macOS 14 or later and supports Apple silicon and Intel. Open the DMG and drag Walkthrough to Applications.

Upgrading from Listing Namer? Walkthrough is the same app with a new name. Your saved jobs, naming presets, and settings remain compatible.

Use Walkthrough → Check for Updates to get the latest release. Sparkle downloads the update inside the app, then offers Install and Relaunch. The current release is 1.4.1. Automatic checking is optional in Settings → General. No app account is needed. See release notes for the update history, also available from Help → Release Notes and Settings → General.

Moved folders and local jobs

If a source folder moves, use Locate Job Folder in the File menu. An ordinary photo folder opened on another Mac starts a new job. Organization history stays in the local app library.
