Availability and updates

Install Walkthrough, check system requirements, and use in-app updates.

Walkthrough requires macOS 14 or later and supports Apple silicon and Intel. Open the DMG and drag Walkthrough to Applications.

Upgrading from Listing Namer? Walkthrough is the same app with a new name. Your saved jobs, naming presets, and settings remain compatible.

Use Walkthrough → Check for Updates to get the latest release. Sparkle downloads the update inside the app, then offers Install and Relaunch. See the download page for the current release. Automatic checking is optional in Settings → General. No app account is needed. See release notes for the update history, also available from Help → Release Notes and Settings → General.
