How Smooshed was tested

Smooshed was compared with JPEGmini Pro and two widely used JPEG encoders, MozJPEG and libjpeg-turbo, on two sets of photos: 1,147 photos from real shoots and 100 public test images. Each comparison looks at total file size and how closely the smaller files match the originals.

1,147 photos from real shoots

The batch started at 13.37 GB and included edited exports and straight-from-camera JPEGs.

Smooshed brought it down to 5.78 GB, saving 56.8%, a little smaller than JPEGmini Pro’s 5.80 GB, with nearly the same image score. MozJPEG made the smallest files at the setting tested, with a lower score.

100 public test photos

On a public image set anyone can download, Smooshed cut the batch from 108.41 MB to 62.96 MB. JPEGmini Pro finished at 62.00 MB. All four tools landed close together on image score.

How the comparison worked

Every tool got the same photos, and every output kept the original dimensions. Smooshed used its automatic setting. MozJPEG and libjpeg-turbo were run at quality 85, a common choice for photos.

The image score is SSIMULACRA2, an automated measure of how closely a compressed photo matches the original. The tables show the median photo’s score.

Smooshed’s automatic setting was tuned on many of these photos, so new work may land a little further from JPEGmini Pro’s sizes.
